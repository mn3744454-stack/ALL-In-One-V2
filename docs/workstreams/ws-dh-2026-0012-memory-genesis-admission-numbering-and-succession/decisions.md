## Local Decision ID convention

`docs/CONVENTIONS.md` §11.1 fixes the Decision ID format for a Roadmap package as `DEC-<Roadmap ID>-NNN`, consecutive. No Workstream package in this repository has previously carried a `decisions.md`, so there is no pre-existing Workstream decision convention to inherit. The convention applied here is the direct, minimal extension of §11.1 to a Workstream package:

```text
DEC-WS-DH-2026-0012-NNN
```

Consecutive, zero-padded to three digits, never renumbered, never reused.
