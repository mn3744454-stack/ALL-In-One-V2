# RM-DH-003 — Roadmap & Workstream Governance Foundation

**العنوان العربي:** تأسيس حوكمة خرائط العمل ومسارات العمل

## Purpose

Establish a durable, truthful, bilingual governance layer for Dayli Horse Roadmaps and Workstreams inside the repository, so that work items, decisions, evidence, and stopping points remain understandable over a very long horizon and independent of any private conversation history.

This README owns **stable identity and navigation only**. Current state lives in [`roadmap.md`](./roadmap.md).
