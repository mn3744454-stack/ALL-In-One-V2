# Dayli Horse — Central Roadmap Registry

**العنوان العربي:** السجل المركزي لخرائط العمل — ديلي هورس

This registry is an **index only**. It is not a competing copy of any Roadmap's authoritative content.

## Registry rules

1. Each Roadmap owns its own four-file package. The registry links to that package.
2. Registry summaries **never override** a Roadmap's authoritative files. Where the registry and a Roadmap's `roadmap.md` disagree, `roadmap.md` is authoritative and the registry row is a defect to be corrected.
3. A new Roadmap may be registered only after repository evidence exists for it and the Dayli Horse Platform Owner has approved its creation and structural classification.
4. Full Phase content, decision content, and change history are **not** copied here.
5. Roadmap ID format is `RM-DH-###`. Phase references must always use the compound form `RM-DH-00X / Phase N`.
